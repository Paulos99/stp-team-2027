# STP — Crush test

## Как запустить

1. Распакуйте ZIP целиком.
2. Откройте папку stp-sound-battle и дважды щёлкните по index.html.
3. Нажмите «Начать игру». Кнопка «Сыграть ещё раз» сразу запускает новое прохождение с выхода героя, минуя заставку. Кнопка «Пропустить» открывает экран заявки.

Для игры не нужен интернет, сервер или установка. Звуковые эффекты включаются после нажатия «Начать игру». Кнопка «Звук вкл./выкл.» отключает или включает их в любой сцене. На телефоне предусмотрена вертикальная компоновка, а режим уменьшения движения использует короткие статичные переходы.

## Анкета

В js/config.js задайте applicationUrl с полным HTTPS-адресом Яндекс Формы. Надпись меняется в applicationLabel. Пока адрес пуст, кнопка объясняет, что анкета ещё не подключена.

## Как встроить игру в существующий HTML-лендинг

Скопируйте папку целиком в каталог сайта. Пример для HTML-страницы, рядом с которой лежит папка игры.

```html
<iframe
  id="stp-game"
  src="./stp-sound-battle/index.html"
  title="STP — Crush test"
  allow="autoplay"
  loading="lazy"
  style="display:block; width:100%; height:clamp(540px, 85svh, 850px); border:0">
</iframe>
```

На смартфоне оставьте блоку полную ширину и около 540–740 px высоты. На десктопе используйте широкую композицию с высотой около 600–850 px. Внутренние стили и управление изолированы в iframe.

Для событий заполните parentOrigin точным HTTPS origin лендинга, например https://example.com. Оставьте applicationUrl пустым, если открытием анкеты управляет лендинг. Игра отправляет только действие и версию протокола. На лендинге проверяйте источник окна, origin игры и структуру события. Если игра размещена на том же origin, используйте следующий пример. При раздельном размещении укажите точный origin игры вместо location.origin.

```js
const gameFrame = document.getElementById("stp-game");
window.addEventListener("message", (event) => {
  if (event.source !== gameFrame.contentWindow || event.origin !== location.origin) return;
  const message = event.data;
  if (message?.source !== "stp-sound-battle" || message.version !== 1) return;
  if (message.action === "apply") {
    document.querySelector("#application")?.scrollIntoView({ block: "start" });
  }
  if (message.action === "skip") {
    // При необходимости обработайте пропуск на лендинге.
  }
});
```

## Графика и постановка

Проходка использует рисунки ключевых поз, движение по перспективе и параллакс. Открывание передней и задней дверей, капота и багажника показано последовательным переходом между нарисованными состояниями кузова. Перед выездом панели закрываются. Крупный план монтажа — игровая схема, с листом на металле передней двери. Капот открывается в кадре мастерской. Зоны применения материала сверены по карточке StP: https://stp-russia.ru/catalog/vibropogloshchayushchie-materialy/bronner-spl/

Показания шкалы и исходы заезда относятся к вымышленному сюжету.



Открытый кузов в мастерской заменён на макет заказчика. Прозрачный фон подготовлен встроенным imagegen. Файл графики — assets/cars/customer-open-car.png.


## Проигрышная сцена

При комиксном взрыве весь автомобиль разделяется на анимированные фрагменты. Кузов исчезает, остаётся кучка пепла с дымом. Дым продолжает подниматься до повторного запуска, а повтор очищает эффекты. При уменьшении движения используются статичные дымные облака. Графика пепла подготовлена встроенным imagegen по фотографии заказчика, файл assets/effects/ash-pile.png.


## Звуковые эффекты

В игре используются восемь MP3 заказчика из assets/audio. Они проигрываются локальным медиаплеером. Внешние сервисы не требуются. Громкость регулируется параметром soundVolume от 0 до 1 в js/config.js. soundEnabled задаёт исходное состояние кнопки. Выключение звука сохраняется при повторном прохождении. В скрытой вкладке звук приглушается. Если запись не загружается, игра продолжает работать, а кнопка показывает «Ошибка звука».

В iframe оставьте allow="autoplay" из примера подключения, чтобы лендинг разрешал воспроизведение звука игры. Первый запуск звука всё равно происходит по действию пользователя.


| Исходный файл | Сцена | Файл в игре |
| --- | --- | --- |
| звук шагов.mp3 | Выход героя | steps.mp3 |
| звук поъезда машины (mp3cut.net).mp3 | Появление автомобиля | arrival.mp3 |
| звук монтажа листов.mp3 | Установка и прикатка листа | install.mp3 |
| звук на заезд на замер.mp3 | Выезд на площадку | drive.mp3 |
| звук на замер (mp3cut.net).mp3 | Замер | measure.mp3 |
| звук взрыва машины (mp3cut.net).mp3 | Взрыв и разлёт | explosion.mp3 |
| Звук победы.mp3 | YOU WIN! | win.mp3 |
| Звук проигрыша.mp3 | GAME OVER | lose.mp3 |

MP3 скопированы без изменения содержимого. При смене сцены её запись останавливается. Шаги прекращаются с остановкой героя, звук монтажа слышен во время установки листа. Длинные записи звучат в пределах своей сцены. При коротких записях шаги, монтаж и замер могут повторяться до завершения соответствующего действия.



Во время игрового замера шкала и число нарастают от 0 до 161 дБ. Максимум удерживается перед финалом. Надпись «Игровой показатель» обозначает художественное значение сюжета.
